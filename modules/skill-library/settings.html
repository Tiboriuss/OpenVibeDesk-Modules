Skill-Bibliothek Skill Library

Skills im Chat anwenden Use skills in chat

Öffne die Skill-Bibliothek über das Dock. Ziehe einen gespeicherten Skill in den Chat oder wähle Im Chat verwenden. Ergänze deine Anfrage und bei Bedarf eine Mail oder Datei als weitere Referenz. Open the Skill Library from the dock. Drag a saved skill into chat or choose Use in chat. Add your request and, if needed, an email or file reference.

Die Anweisungen gelten für die folgende gesendete Anfrage. Das Anhängen allein startet keine Aktion. Zum Anwenden deiner Änderungen bitte zuerst speichern. The instructions apply to the next request you send. Attaching the skill alone does not start an action. Save any edits before using the skill.

Beim Senden wird der ausgewählte Skill zusammen mit deiner Anfrage an den gewählten KI-Anbieter übermittelt und als Momentaufnahme im Chat gespeichert. When you send a request, the selected skill is sent to your AI provider and a snapshot is saved in the chat.

Kacheln, Kategorien und Favoriten Tiles, categories and favorites

Jeder Skill erscheint als Kachel. Links findest du immer Alle und Favoriten sowie die Kategorien deiner Skills. Der Stern markiert einen Favoriten, der Stift öffnet den Editor. Each skill has its own tile. The category list includes All, Favorites and your custom categories. Use the star to mark a favorite and the pencil to open the editor.

Eine eigene Kategorie trägst du im Editor ein. Ohne Kategorie bleibt ein Skill über Alle und Ohne Kategorie erreichbar. Enter a custom category in the editor. Skills without a category appear under All and Uncategorized.

Mit dem Assistenten pflegen Manage skills with the Assistant

Der Assistent kann auf deinen Wunsch Skills anlegen, suchen, lesen, bearbeiten, kategorisieren, favorisieren und löschen. Er verwendet denselben lokalen Speicher und dieselben Funktionen wie das Bibliotheksfenster. Ask the Assistant to create, find, read, edit, categorize, favorite or delete skills. The Assistant uses the same local storage and tools as the library window.

„Speichere diese Arbeitsweise als Skill mit dem Titel Kundenmails beantworten.“ “Save this workflow as a skill called Reply to customer emails.”

„Suche den Skill für Kundenmails und ergänze, dass keine Termine zugesagt werden sollen.“ “Find the customer email skill and add an instruction to avoid promising dates.”

Änderungen an vorhandenen Skills prüfen die gespeicherte Version. Wenn ein Skill zwischenzeitlich geändert wurde, muss der aktuelle Stand zuerst gelesen werden. Changes to an existing skill are checked against its saved revision. If someone has edited it, read the latest version before making another change.

Lokaler Speicher und Grenzen Local storage and limits

Deine Skills liegen im eigenen Datenverzeichnis dieses Moduls. Modulupdates erhalten diese Daten. In der Bibliothek werden nur die Skills geladen, die du gerade suchst oder öffnest. Your skills are stored in the module’s data directory and are preserved when the module is updated. The library loads only the skills you search for or open.

Die Bibliothek unterstützt bis zu 500 Skills. Jeder Skill enthält Titel, Kurzbeschreibung, Kategorie, Favoritenstatus, optionale Tags und bis zu 6000 Zeichen Arbeitsanweisungen innerhalb der Speichergrenze von 8192 UTF-8-Bytes. The library holds up to 500 skills. Each skill has a title, description, category, favorite status, optional tags and up to 6,000 characters of instructions within a limit of 8,192 UTF-8 bytes.
